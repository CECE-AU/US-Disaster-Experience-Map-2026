Methodology & Map Calculations

State-Level Percentages: Because respondents could skip individual hazard items on the survey, state percentages for each disaster category are calculated using the exact number of valid responses to that specific question in that state (nquestion) rather than the overall state sample size:
State Percentage = (Respondents Experiencing Hazard / Total Valid Responses to Question) × 100
Pooled Natural Breaks (Fisher-Jenks): When "Natural Breaks (Jenks)" is selected, states are grouped into 5 discrete classes using the Fisher-Jenks optimization algorithm. This method identifies natural groupings in the data by minimizing variance within each class and maximizing variance between classes. To allow direct visual comparison across years, break thresholds are calculated per disaster category using the pooled 2025 and 2026 state values—meaning the 5 color bins represent the exact same percentage ranges when toggling between 2025 and 2026.
Equal Intervals ("Interval/Scale"): For the 2025 and 2026 views, toggling to "Interval/Scale" switches the legend from data-driven clusters to 5 fixed 20% increments (0.0%–20.0%, 20.1%–40.0%, 40.1%–60.0%, 60.1%–80.0%, and 80.1%–100.0%), allowing direct comparison across different disaster types.
Percentage Point Shift (2025–2026): Rather than relative percent change (which exaggerates small baseline numbers), year-over-year change is measured as the arithmetic difference in percentage points between waves:
Percentage Point Shift = Percentage2026 − Percentage2025
For example, a state moving from 20.0% in 2025 to 30.0% in 2026 reflects a +10.0 percentage point shift. This view uses a continuous diverging color scale locked from −50% to +50% (centered at 0%) and compares a 6-month recall window in October 2025 against a 12-month recall window in October 2026.
